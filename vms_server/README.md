# ArgOS VMS 서버 (열화상 IR-301)

데모 봇(카메라 역할)이 보내는 IR 측정값을 받아 **단계를 직접 판정**하고, 값과 단계를 **REST로 메인 서버에 전달**합니다.
2단계·3단계에 처음 진입한 순간에는 **ROI + 스냅샷**도 함께 보냅니다. 3단계일 때만 **영상 주소**를 엽니다.
표준 라이브러리만 쓰므로 설치할 것이 없습니다 (Python 3).

```
데모 봇(카메라 역할) ──HTTP POST /ir──▶ VMS 서버 ──REST──▶ 메인 서버
                                          │ 3단계일 때만
                       대시보드 ◀──영상──┘ GET /stream/IR-301
```

## 실행 순서 (같은 컴퓨터, 터미널 3개)
```
cd 바탕화면\shy_ws\vms_server
python mock_main_server.py                 # (1) 진짜 메인 서버가 없을 때만: 메인 서버 대역, 포트 8080
python vms_server.py                       # (2) VMS 서버, 포트 9000
cd ..\demo_bot
python demo_bot.py --dry-run               # (3) 봇 (실제 전송은 --dry-run 빼고)
```
진짜 메인 서버가 있으면 (1)은 건너뛰고 `python vms_server.py --main-url http://메인서버주소/vms/ir` 로 실행합니다.

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--host` / `--port` | `0.0.0.0` / `9000` | VMS 서버가 받을 주소 (봇의 `--vms-url`과 맞춤) |
| `--main-url` | `http://127.0.0.1:8080/vms/ir` | 메인 서버 IR 수신 주소 |
| `--no-forward` | | 메인 서버로 보내지 않고 판정만 화면에 표시 |
| `--roi` | `assets\상도건조로_IR_roi.json` | ROI 좌표 파일 |
| `--snapshot-dir` | `assets\snapshot` | 스냅샷 사진 폴더 |
| `--video` | `assets\상도건조로_IR_3단계_영상.mp4` | 3단계 때 내보낼 영상 |
| `--quiet` | | 매 초 한 줄 표시를 끔 (단계 변화만 표시) |
| `--no-browser` | | 시작할 때 크롬(대시보드)을 자동으로 열지 않음 |

## 받는 쪽: 봇 → VMS
`POST /ir` 에 JSON 한 건 (1초마다). 단계는 VMS가 판정하므로 `stage`는 없습니다.
```json
{"ts":"2026-11-16 09:02:10","type":"IR","serial":"IR-301","value":61.2,"unit":"℃","quality":"GOOD"}
```

## 판정 규칙 (IR-301 ROI 최고온도)
- 3단계: 60 ℃ 초과가 **15회 연속**
- 2단계: 50 ℃ 초과가 **15회 연속**
- 복귀: 50 ℃ 이하가 **20회 연속** → 1단계
- 한 번 올라간 단계는 복귀 조건을 만족할 때까지 유지합니다 (3단계에서 값이 50~60 ℃로 내려와도 3단계 유지).
- 기준값과 횟수는 `vms_server.py` 맨 위의 `T_STAGE2, T_STAGE3, N_STAGE2, N_STAGE3, N_RECOVER`에서 바꿉니다.
- 온도 상승 속도 조건(3 ℃/분 이상)은 아직 넣지 않았습니다.

## 보내는 쪽: VMS → 메인 서버 (`--main-url`)
**평소 (매 초)** `application/json`
```json
{"ts":"2026-11-16 09:02:12","type":"IR","serial":"IR-301","value":61.9,"unit":"℃","quality":"GOOD","stage":1}
```
**단계에 진입한 순간 (한 번)** `multipart/form-data`
- `meta` = 위 JSON + ROI
```json
{"ts":"2026-11-16 09:02:24","type":"IR","serial":"IR-301","value":64.9,"unit":"℃","quality":"GOOD","stage":3,
 "roi":{"roi_id":"ROI-01","frame":{"width":640,"height":480},"bbox":{"x1":30,"y1":34,"x2":330,"y2":370}}}
```
- `snapshot` = 진입 시각과 같은 이름의 사진 (예: `IR-301_20261116_090224.jpg`). 같은 시각 사진이 없으면 가장 가까운 시각의 사진을 씁니다.
- 1단계에서 3단계로 바로 올라가면 진입 메시지는 3단계 한 번만 갑니다.

메인 서버에 못 보내면 경고를 한 번 띄우고, 못 보낸 데이터는 쌓지 않고 버립니다.

## 영상 (3단계일 때만)
`GET /stream/IR-301` → 3단계면 mp4를 내주고(구간 요청 `Range` 지원), 아니면 404.
대시보드의 `sensor.stream_url`에 이 주소를 넣으면 됩니다. 영상은 저장하지 않습니다.
(시연용으로 mp4 파일을 그대로 내주는 방식이고, 실제 카메라가 붙으면 HLS/WebRTC 같은 방식으로 바뀔 수 있습니다.)

## 값 보기 (자동 갱신)
서버를 실행하면 크롬에서 `http://127.0.0.1:9000/` 가 자동으로 열립니다 (원하지 않으면 `--no-browser`). 이 화면을 열어 두면 1초마다 저절로 갱신됩니다 (새로고침 필요 없음).
현재 온도, 단계(1/2/3), 연속 횟수, 최근 값 그래프(50 ℃·60 ℃ 기준선), **봇(카메라 역할)이 보낸 요청 원본(받은 그대로, 최근 40건)** 이 보이고, 3단계가 되면 아래에 실시간 영상이 나타납니다.
(크롬 같은 일반 브라우저를 권장합니다. VS Code 안의 브라우저는 영상이 재생되지 않을 수 있습니다.)

## 상태 확인 (JSON)
`GET /status` → 받은 건수, 센서별 단계·마지막 값·연속 횟수·최근 값, 메인 서버로 보낸 건수/버린 건수.

## 폴더 구성

```
assets\                ROI 좌표, 스냅샷 사진 40장, 3단계 영상
```
